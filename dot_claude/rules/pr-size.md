# PR Size

- Effective logic (excluding generated code, tests, data) per PR: **≤ 300 LOC**. Over the limit → split independent changes into separate PRs
- 1 PR = 1 purpose; a PR serving multiple "why"s → split
- Unavoidably large → label core changes vs mechanical changes in the PR description
- Commit granularity: 1 commit = 1 logical change (100-200 LOC)
